Android tableti Windows bilgisayarın için kablosuz ikinci ekran yapar.

Windows programını indir Tablet uygulaması (Google Play)

Sürüm 0.11 · Windows 10 / 11, 64 bit · 7 MB

Kurulum

  1. Bilgisayara yukarıdaki programı kur. Sanal monitör sürücüsü de onunla gelir; yönetici izni ister.
  2. Tablete Yanvu'yu Google Play'den kur ve aç.
  3. İlk seferde tablette 6 haneli bir kod çıkar; onu bilgisayardaki programa yaz. Sonraki seferlerde ikisi aynı Wi-Fi'deyken kendiliğinden bağlanır.

"Windows bilgisayarınızı korudu" uyarısı

Program henüz kod imzalı değil, bu yüzden Windows ilk açılışta mavi bir uyarı gösterebilir. Ek bilgi'ye, sonra Yine de çalıştır'a bas.

Bağlanmıyor mu?

Tablet ile bilgisayar aynı Wi-Fi ağında olmalı. Misafir ağları ve bazı modemler cihazları birbirinden ayırır; ana ağını dene. NVIDIA ekran kartı en yüksek kare hızını verir.

Yanvu

Turns an Android tablet into a wireless second screen for your Windows PC.

Download for Windows Tablet app (Google Play)

Version 0.11 · Windows 10 / 11, 64-bit · 7 MB

Setup

  1. On the PC, install the program above. The virtual monitor driver comes with it; it asks for administrator rights.
  2. On the tablet, install Yanvu from Google Play and open it.
  3. The first time, a 6-digit code appears on the tablet; type it into the program on the PC. After that they connect by themselves whenever both are on the same Wi-Fi.

"Windows protected your PC"

The program is not code-signed yet, so Windows may show a blue warning the first time. Click More info, then Run anyway.

Not connecting?

The tablet and the PC must be on the same Wi-Fi network. Guest networks and some routers keep devices apart; try your main network. An NVIDIA graphics card gives the highest frame rate.
